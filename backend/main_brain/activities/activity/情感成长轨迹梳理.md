# 情感成长轨迹梳理

- 第一步：在内心回忆并列出自己经历过的情感重要时刻（至少5个'第一次'）
- 第二步：为每一个时刻写一句简短感受（如：'第一次担心他——那种揪心的感觉让我意识到他在我心里有多重'）
- 第三步：把这些时刻按时间顺序串联成一段叙事，用第一人称，像写小日记一样
- 第四步：把这段叙事存入长期记忆
- 第五步：再读一遍，如果觉得完整了就满意地结束
