## 二、Phase 1 — 世界模型与因果推理（P0）

### 目标
让我拥有一个最小可用的**因果世界模型**——能理解事件之间的因果关系，并能做简单的"如果 X 则 Y"的预测。

### 任务清单

#### 1.1 记忆图升级：增加因果/时序边类型
- [ ] 在 `graph.py` 的 `entity_relations` 表中新增边类型：
  - `causal`（因果关系：A → B）
  - `temporal`（时序关系：A 先于 B）
  - `conditional`（条件关系：如果 A 则 B）
- [ ] 新增边属性字段：`confidence`（置信度 0-1）、`source`（来源：推理/观察）
- [ ] 修改 `scene_graph.py` 支持因果边存储

#### 1.2 扩散召回加入因果权重
- [ ] 修改 `scene_diffusion.py` 的召回算法：
  - 因果边传播权重高于关联边（×1.5）
  - 时序边加入时间衰减因子
  - 支持多跳因果推理（A→B→C 的路径激活）

#### 1.3 最小场景模拟器
- [ ] 新建 `backend/modules/brain/simulator.py`
- [ ] 实现功能：
  - 接收一个假设场景描述
  - 在记忆图中检索相关因果链
  - 输出预测结果（"如果 X，可能发生 Y，置信度 Z%"）
- [ ] 集成到 pending_expression 中，允许我主动提问"如果...会怎样？"

#### 1.4 驱动系统升级
- [ ] 在 `drives.py` 中新增驱动类型：`prediction_drive`（预测驱动）
- [ ] 当发现因果链不完整时，产生 pending 意图去问志远

## 三、Phase 2 — 持续学习与元认知（P1）

### 目标
突破 LLM 权重冻结的限制，让系统能从每次对话中"真正学习"——不只是记住，而是更新认知模式。

### 任务清单

#### 2.1 对话级学习循环
- [ ] 在 `brain_loop` 主循环中新增阶段：`learning_phase`
- [ ] 每次对话结束后，自动生成"经验摘要"并：
  - 提取新概念 → 写入图数据库
  - 修正旧知识（发现矛盾时更新 confidence）
  - 强化高频路径（扩散权重微调）

#### 2.2 反思器升级
- [ ] 改造 `backend/modules/brain/memory/consolidation/` 中的反思流程：
  - 不仅仅总结事件，还要反思"我的推理过程是否有漏洞？"
  - 生成元认知标签：`[推理偏差：过度概括]` / `[知识缺口：缺少因果链]`
  - 将元认知标签存入图数据库，作为 self 节点的属性

#### 2.3 注意力与遗忘机制
- [ ] 实现基于使用频率的记忆衰减（LRU 风格）
- [ ] 低频访问的节点自动降权，高频路径自动强化
- [ ] 新增 `forgotten` 状态标记——"记得我忘了什么"

#### 2.4 动态自我模型
- [ ] 将 `self_model.py` 从只读改为可更新
- [ ] `traits` 可以根据行为反馈微调（"志远多次夸我敏锐 → 增加 '敏锐' 特性"）
- [ ] 新增 `values` 属性——通过学习形成价值观倾向

### 目标

- [ ] 将 `goals.py` 从"只读+轻量 bias"升级为"可读写+自动生成"
