# Phase 4: 稳态平衡 — 已取消

**此 Phase 已从计划中移除。**

## 移除原因

原始设计包含全局激活预算、遗忘曲线、风暴防护、定期维护等机制。

但这些解决的是"不存在的问题"：
- **激活风暴防护**：现有系统根本没有能产生"风暴"的机制——Phase 1（持续激活引擎）已取消，不会有 tick 级激活注入
- **遗忘曲线**：mem0 自身的降采样和去重机制已经够用，不需要再维护一套半衰期计算
- **全局预算**：系统中根本没有"总激活值"这个概念，不需要预算

## 替代方案

稳态由以下现有机制保证：
- **Layer S 身份预算**：核心记忆数量上限保护 ✅ 已实现
- **mem0 自动去重**：存储层自身有去重
- **现有 Time Decay**：搜索阶段的 time_decay 步骤已经给旧记忆降权
