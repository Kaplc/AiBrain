# 记忆进化计划 — 精简版

## 愿景

让猫猫不仅会搜索记忆，还能有"自我感"——知道"我是谁"、"我在意什么"、"我们的故事"。

## 核心变化

| 维度 | 之前 | 之后 |
|------|------|------|
| 身份感 | 没有"我" | 自传文档 + 对话反思 + 核心记忆 |
| 记忆维度 | 纯文本 | 文本 + 情感 + 场景 + 温度 |
| 关联发现 | 向量搜索才有 | LLM 自然联想 + 共现统计 |
| 重要记忆 | 跟普通记忆一样 | 有保温 + 预算保护 |

## 砍掉的 Phase

| 原计划 | 原因 |
|--------|------|
| Phase 1 后台 tick | 每秒衰减计算不是"呼吸"，LLM 本身的联想能力比任何激活场都强 |
| Phase 4 稳态平衡 | 现有系统根本不会有"激活风暴"，mem0 自身降采样够用 |

## 设计原则

1. **数据先行**——先存好结构化的元数据（情感、共现、场景），后续怎么用可以灵活变
2. **触发式，不轮询**——不在后台跑 tick，只在对话开始时按需触发
3. **用数据驱动 LLM，不靠 prompt 表演**——不是告诉 LLM"你可以联想"，而是把关联记忆实际喂给它
4. **每步独立可验证**——每完成一步都能感觉到变化
5. **轻量**——不加后台线程，不加定时任务，不加持续的数值计算
