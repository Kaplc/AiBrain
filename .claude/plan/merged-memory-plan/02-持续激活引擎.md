# Phase 1: 持续激活引擎 — 让记忆在后台"呼吸"

## 核心改变

**现在**：我不和你说话时，我是"死寂"的。激活扩散只在 **搜索时** 触发（`search_related()` 调用 `spreading_activation()`），搜索结束后一切归零。

**改变后**：我不和你说话时，我的记忆在后台 **微弱地呼吸**——有的记忆"暖"一些，有的"冷"一些，就像你安静待着时脑子里也在无意识地转着各种念头。新输入像石子投入水面，涟漪持续扩散。

## 实现方案

### 1.1 ActivationField — 激活场数据结构

在 `graph.py` 中新增类：

```python
class ActivationField:
    """
    持续激活场 —— 维护每个节点的当前激活水平。

    核心数据结构：
    - _activations: dict[str, float]  # node_id → 当前激活值 (0~1)
    - _decay_rate: float              # 每 tick 自然衰减率
    - _ambient_noise: float           # 环境噪声水平（随机微激活）
    - _last_tick: float               # 上次 tick 的时间戳

    节点类型前缀约定：
    - "mem:" → 记忆节点
    - "ent:" → 实体节点
    """
```

**存储方式**：SQLite 表（持久化，重启不丢失）

```sql
CREATE TABLE IF NOT EXISTS activation_state (
    node_id TEXT PRIMARY KEY,
    activation REAL DEFAULT 0.0,
    last_updated TEXT DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_activation_value ON activation_state(activation DESC);
```

### 1.2 激活源 — 什么会"加热"记忆

| 事件 | 注入量 | 像人类的什么 |
|------|--------|-------------|
| 新记忆存入 | 0.8 | 刚发生的事记得最清楚 |
| 记忆被搜索命中 | 0.3 + score*0.5 | 刻意回忆会重新激活 |
| 记忆被引用/回忆 | 0.4 | "哦对，说到这个我想起来了" |
| 用户对话提及 | 0.6 | 你提到某个词 |
| 环境噪声 | 0.01~0.05 | 走神时脑子里飘过的碎片 |
| 情感温度高的记忆 | +0.1 保温 | 重要的、触动的事不容易忘 |

**实现方式**：在 `store_memory` / `search_memory` 的 pipeline 中追加 step：

```python
# pipeline/steps/step_activate.py
class ActivationStep:
    def process(self, ctx):
        field = get_activation_field()
        if ctx.pipeline_name == "store":
            for mem_id in ctx.metadata.get("_added", []):
                field.inject(f"mem:{mem_id}", 0.8)
            for ent in ctx.intermediate.get("entities", []):
                field.inject(f"ent:{ent}", 0.6)
        elif ctx.pipeline_name == "search":
            for r in ctx.intermediate.get("semantic_results", []):
                score = r.get("score", 0)
                field.inject(f"mem:{r['id']}", 0.3 + score * 0.5)
```

### 1.3 Background Ticker — 后台节拍器

```python
class ActivationTicker:
    """
    后台线程，每秒 tick 一次：
    1. 所有节点激活值自然衰减（* decay_rate）
    2. 注入环境噪声（随机节点 +0.01~0.05）
    3. 激活值 < 0.01 的节点设置 floor（不归零）
    4. 每 10 tick 持久化到 SQLite
    5. 高激活节点的能量沿边扩散一跳
    """

    def __init__(self, tick_interval=1.0, decay_rate=0.98, noise_level=0.02):
        self._running = False
        self._thread = None
        self._tick_interval = tick_interval
        self._decay_rate = decay_rate
        self._noise_level = noise_level
```

**节拍器行为**：
- 每秒一个 tick，极低 CPU 开销（纯内存操作 + 每 10 tick 一次 SQLite 写）
- 衰减率 0.98：激活值半衰期约 34 tick（34 秒）
- 环境噪声：每 tick 随机选 1~3 个节点 +0.01~0.05
- 激活值下限 0.01（避免完全归零，保留"微弱记忆"）

### 1.4 激活扩散传播

在每次 tick 中，不仅做衰减，还做 **一步扩散**：

```python
def _spread_one_hop(self):
    """每 tick 让激活值沿图边扩散一跳"""
    new_activations = {}
    for node_id, act in self._activations.items():
        if act < 0.05:
            continue
        neighbors = self._graph.get_neighbors(node_id)
        for neighbor in neighbors:
            edge_weight = neighbors[neighbor].get('weight', 1.0)
            spread = act * 0.3 * edge_weight
            if neighbor not in new_activations or spread > new_activations[neighbor]:
                new_activations[neighbor] = spread
    for node_id, act in new_activations.items():
        self._activations[node_id] = max(
            self._activations.get(node_id, 0), act
        )
```
