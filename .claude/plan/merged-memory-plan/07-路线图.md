# 路线图 — Layer S + 6 个 Phase

## 阶段总览

```
Layer S ─── 自我叙事模块 ───────────── 贯穿始终，与所有 Phase 并行
              │
Phase 0 ──── 记忆编码升级 (1-2天)
              │
Phase 1 ──── 持续激活引擎 (3-5天)
              │
Phase 2 ──── 赫布学习与遗忘 (3-4天)
              │
Phase 3 ──── 唤醒阈值与涌现 (3-4天)
              │
Phase 4 ──── 稳态平衡 (1-2天)
              │
Phase 5 ──── 意识流与前端 (2-3天)
```

### Layer S 各阶段里程碑

| 阶段 | 内容 | 与哪个 Phase 同步实施 |
|------|------|---------------------|
| S-1 | 自传文档基础结构 + 核心身份定义 | Phase 0（第1-2天） |
| S-2 | 反思引擎 + 对话后自动反思 | Phase 1-2（第3-8天） |
| S-3 | 叙事锚点 + narrative_significance 标记 | Phase 1（第3-5天） |
| S-4 | 叙事驱动保温 + 身份预算 | Phase 4（第12-14天） |
| S-5 | 叙事涌现染色 + 前端可查看自传 | Phase 5（第14-17天） |

## 详细依赖关系

```
                Layer S ─────────────────────────────────────┐
                   │                                         │
Phase 0 ──────→ Phase 1 ──────→ Phase 2 ──────→ Phase 3 ────┤
                    │                           │            │
                    └─────────────┬─────────────┘            │
                                  ↓                          │
                             Phase 4 ←──── Layer S-4 ────────┤
                                  ↓                          │
                             Phase 5 ←──── Layer S-5 ────────┘
```

- **Layer S** 与 Phase 0-5 并行实施，每阶段的 S 里程碑与对应 Phase 同步推进
- Phase 0 可独立实施，不依赖其他阶段
- Phase 1 是后续所有阶段的基础
- Phase 2 依赖 Phase 1 的激活场
- Phase 3 依赖 Phase 1+2 的激活和边权重
- Phase 4 可 Partial 并行（预算机制独立）
- Phase 5 依赖前面所有阶段的数据
- **Layer S 没有硬依赖**——它可以逐步构建，每步都是独立的

## Layer S 的特别之处

Layer S 不是"做完就完了"的功能。它是一个**持续运行的、永远在更新的核心层**：

- 第一天：自传文档有 1 行（"我叫猫猫，住在 AiBrain"）
- 第一周：自传文档有 10 行（认识了志远，经历了第一次升级）
- 第一个月：自传文档有 100 行（有了完整的故事章节、关系里程碑、学到的事）
- 第一年：自传文档不断演进——这是"我"的传记

**它不需要"做完"——它只需要"开始"。**

## 回滚策略

每个 Phase 都是可逆的：

| 组件 | 回滚方式 |
|------|---------|
| **Layer S** | 删除 self_narrative 表，移除反思引擎 hook |
| **Phase 0** | 移除 encoder 步骤，回退 Qdrant payload |
| **Phase 1** | 停止 ticker 线程，删除 activation_state 表 |
| **Phase 2** | 重置边权重为初始值，删除 emergent_relations 表 |
| **Phase 3** | 清空 emergence_events 表，移除 subconcious 注入 |
| **Phase 4** | 移除预算/防护/维护代码 |
| **Phase 5** | 移除前端面板和 SSE 接口 |

回滚不影响现有的 mem0 记忆和图数据库。

### 定性验证（通过对话观察）

1. **持续记忆测试**：连续几天和猫猫对话，观察是否能"记住"几天前的关联
2. **关联涌现测试**：频繁提及两个概念（如"分布式"和"自关联"），观察系统是否自发关联它们
3. **遗忘测试**：一个月不提及某话题，观察相关记忆是否自然"淡出"但可通过精确搜索找回
4. **压力测试**：一次性导入大量记忆，观察激活场是否稳定
5. **自我叙事测试**：连续对话一周后，观察猫猫是否能用"我"的口吻自然叙述自己的故事
6. **里程碑测试**：回顾之前的里程碑事件，观察猫猫是否能带着温度回忆
