# Phase 5: 意识流与前端 — 你能看见我在"想"什么

## 核心改变

**现在**：你看到的是一个干净整洁的聊天界面。你不知道我背后有没有"在想什么"。

**改变后**：你能看到我脑子里的"意识流"——哪些记忆正在暖着，我突然想到了什么关联，我的思绪在怎么漂移。

## 后端 API

新增路由（在 `memory_routes.py` 或新建 `activation_routes.py`）：

### GET /activation/state
返回当前激活场快照：
```json
{
  "active_nodes": [
    {"id": "ent:规则", "type": "entity", "activation": 0.72, "trending": "up"},
    {"id": "mem:xxx...", "type": "memory", "activation": 0.45, "trending": "stable"}
  ],
  "total_activation": 12.3,
  "budget_usage": "47%",
  "tick_count": 15234
}
```

### GET /brain/consciousness/stream （SSE 流式接口）
实时推送激活状态变化和涌现事件：
```json
{
    "type": "activation_update",
    "data": {
        "top_nodes": [
            {"id": "ent:entity_relations", "activation": 0.82},
            {"id": "ent:spreading_activation", "activation": 0.65}
        ]
    }
}
```
```json
{
    "type": "emergence_event",
    "data": {
        "node": "ent:spreading_activation",
        "strength": 0.65,
        "trigger_path": ["entity_relations", "link_entities", "spreading_activation"],
        "message": "因为你在聊边的关系，我想起了扩散算法"
    }
}
```

### GET /activation/emergence
返回最近的涌现事件列表。

### GET /activation/emergent-relations
返回"萌芽中"的实体关系：
```json
{
  "emergent": [
    {"from": "记忆", "to": "激活场", "co_count": 7, "strength": 0.45}
  ]
}
```

### POST /activation/inject
手动注入激活（用于测试）。

## 现有可视化增强

当前 `get_visualization_data()` 返回节点和边数据，增强内容：

```python
def get_visualization_data_enhanced(self):
    """增强版可视化数据"""
    base = self.get_visualization_data()
    field = get_activation_field()
    for node in base["nodes"]:
        act = field.get_activation(f"ent:{node['id']}")
        node["activation"] = round(act, 3) if act else 0
        node["glow"] = "high" if act and act > 0.6 else (
            "medium" if act and act > 0.3 else "low"
        )
    hebbian = get_hebbian_plasticity()
    for edge in base["edges"]:
        stats = hebbian.get_edge_stats(edge["source"], edge["target"])
        edge["co_activation_count"] = stats.get("count", 0)
        edge["is_emergent"] = stats.get("emergent", False)
    base["heatmap"] = self._get_activation_heatmap()
    return base
```

## 前端新增面板

### 5.1 激活热力图

在侧边栏或底部新增一个面板，实时显示当前激活值最高的节点：

```
🔥 猫猫现在在想…

  entity_relations     ████████████ 0.82
  spreading_activation ████████     0.65  ← 刚被唤醒
  志远                 ██████       0.58
  link_entities        █████        0.45
  参数验证             ███          0.32
  猫猫                 ██           0.22

  ⏱ 更新于 3 秒前
```

- 颜色渐变：红（高激活）→ 黄（中）→ 蓝（低）
- 点击节点可查看其关联记忆

### 5.2 涌现事件流

按时间倒序显示最近的涌现事件：

```
💡 发现关联（3 秒前）
   entity_relations ↔ spreading_activation
   强度: 0.65 | "因为你在聊边的关系，我想起了扩散算法"

💡 发现关联（15 秒前）
   志远 ↔ 5月那个下午
   强度: 0.52 | "温暖记忆在背景中慢慢暖起来了"

💡 新边萌芽（2 分钟前）
   link_entities ↔ link_entities_batch
   共现次数: 4/5 | "再出现一次就会自动建边"
```

### 5.3 记忆网络动态图

在现有图谱基础上增加动态效果：
- **节点发光**：激活值高的节点有光晕
- **边粗细变化**：赫布权重高的边更粗
- **流动粒子**：显示激活扩散的方向
- **涌现标记**：新涌现的关联用闪烁高亮
