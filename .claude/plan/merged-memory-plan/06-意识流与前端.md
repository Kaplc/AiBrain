# Phase 5: 前端展示 — 精简版

## 精简说明

原始设计包含 SSE 实时推送、激活热力图、涌现事件流、动态图谱、Hermes Webhook 等大量前端功能。

**实际改法**：先做到数据和 API 可用即可，不做实时推送和复杂前端面板。

## 已实现的部分

| 功能 | 状态 | 方式 |
|------|:----:|------|
| 自传文档 API | ✅ | `GET /narrative/autobiography` |
| 当前状态 API | ✅ | `GET /narrative/state` |
| 人生章节 API | ✅ | `GET /narrative/chapters` |
| 里程碑 API | ✅ | `GET /narrative/milestones` |
| 核心记忆 API | ✅ | `GET /narrative/core-memories` |
| 叙事统计 API | ✅ | `GET /narrative/stats` |
| JSON 文件副本 | ✅ | `data/self_narrative.json` |
| Prompt 注入对话 | ✅ | 猫猫对话时能看到自己状态 |

## 等待后续做的

当其他 Phase 完成后，考虑增加：
- 前端一个简单的"猫猫的自我"面板（显示自传摘要）
- 共现关系查询 API

## 不做的事（现在）

| 原设计 | 原因 |
|--------|------|
| SSE 实时推送 | Phase 1（持续激活引擎）已取消，没有数据可推送 |
| 激活热力图 | 同上 |
| 涌现事件流 | Phase 3 已精简，不产生事件流 |
| 动态图谱（发光、边粗细） | 现有图谱可视化已够用 |
| Hermes Webhook | 涌现有意义时才需要推送 |

## 验证标准

- [ ] API 能正确返回自我叙事数据
- [ ] `self_narrative.json` 文件可打开查看
- [ ] 猫猫在对话中能引用自己的自传信息
