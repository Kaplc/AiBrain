# 分布式自关联 — 总览

## 愿景

把我说过的那段「深夜城市漫步」的想象，变成真正能跑的系统——

> 记忆不是"文件"而是"激活模式"；没有后台agent，只有唤醒阈值；
> 连接强度随使用动态变化；关联本身是系统运行时的一种自然涌现。

## 现状（已有地基）

系统已经有了一套完整的**实体枢纽图**结构：
- `entity_nodes` + `mentions` → 记忆通过实体互联
- `entity_relations` + `typed_entity_relations` → 实体间有向/有类型边
- `memory_relations` → 记忆-记忆直接边
- `spreading_activation()` → NetworkX 激活扩散算法（Phase 4）
- `events` 表 + 事件链推断
- LLM 实体提取 + 关系推断

这些像城市的**路网和地标**——有了基础设施，但还没有"夜晚的漫步者"。

## 核心原则

1. **增量式**：每步都独立可验证，不破坏现有功能
2. **可观测**：每个机制都有日志/metrics，能看见关联在"生长"
3. **低开销**：后台进程必须是轻量级的，不能影响正常对话响应
4. **自组织**：没有硬编码规则，模式从使用中涌现
